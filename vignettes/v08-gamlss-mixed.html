1 Purpose

A conventional Gaussian mixed model usually focuses on a conditional mean and one residual scale parameter. Generalized Additive Models for Location, Scale and Shape (GAMLSS) extend the model so that multiple parameters of the response distribution can depend on explanatory variables (Rigby and Stasinopoulos 2005).

This vignette introduces mixed GAMLSS as a scientific extension for questions in which treatment affects not only the mean response but also its variability or other distributional features.

2 1. Learning objectives

You will learn to:

  • distinguish mean modeling from distributional regression;
  • fit a Gaussian GAMLSS with a grouping effect;
  • model residual scale as a function of treatment;
  • inspect fitted mu, sigma, nu, and tau where supported;
  • compare GAMLSS candidates using generalized AIC descriptors;
  • obtain fitted quantiles;
  • diagnose a GAMLSS fit;
  • avoid adding distributional complexity without a scientific rationale.

3 2. Data and scientific question

Use the longitudinal plant-height dataset.

library(mixedFlowR)
z <- mixed_data("longitudinal")
head(z)
#>   subject treatment time   height
#> 1     S01        T1    0 17.27455
#> 2     S01        T1    1 17.38720
#> 3     S01        T1    2 20.55889
#> 4     S01        T1    3 24.15167
#> 5     S01        T1    4 26.40212
#> 6     S01        T1    5 29.13063

Observed variability by treatment:

aggregate(height ~ treatment, z, function(x) c(mean = mean(x), sd = sd(x)))
#>   treatment height.mean height.sd
#> 1        T1   21.882740  5.033957
#> 2        T2   24.545778  5.171771

A difference in raw standard deviations does not prove a treatment effect on conditional scale because time and subject structure are not accounted for. It motivates a distributional question.

  requireNamespace("gamlss", quietly = TRUE) &&
  requireNamespace("nlme", quietly = TRUE)

    height ~ treatment * time,
    data        = z,

#> GAMLSS-RS iteration 1: Global Deviance = 709.0339 
#> GAMLSS-RS iteration 2: Global Deviance = 709.0339

This model is more complex because it combines distributional regression, grouping, and serial correlation. Add such structure only when the design and diagnostics justify it.

13 12. Why modeling sigma can matter biologically

Examples in agronomy include:

  • a biostimulant that increases mean biomass but also produces more heterogeneous plant responses;
  • a stress treatment that leaves the mean similar but increases variability;
  • a cultivar that stabilizes yield under fluctuating conditions;
  • a management practice that changes upper-tail or lower-tail risk.

In these situations, variability can be part of the scientific response rather than nuisance noise.

14 13. Beyond Gaussian location-scale models

GAMLSS supports many distributions, some with additional shape parameters nu and tau. The correct family should be selected based on the response support, distributional behavior, and scientific process.

Do not add nu.formula or tau.formula just because the arguments exist.

A generic example is deliberately shown without execution because the family and interpretation must be chosen for a specific response.

g_shape <- mixed_gamlss(
  y ~ treatment + time,
  data = dat,
  family = chosen_four_parameter_family,  # choose a supported family from the scientific question
  sigma.formula = ~ treatment,
  nu.formula = ~ treatment,
  tau.formula = ~ 1,
  random = "subject"
)

16 15. A decision sequence for GAMLSS

Use GAMLSS when all of the following are plausible:

  1. the distributional parameter is scientifically relevant;
  2. diagnostics suggest a conventional location-only model is inadequate;
  3. the sample contains enough information for the extra submodel;
  4. the distribution family matches response support;
  5. parameter-specific effects can be interpreted meaningfully.

17 16. GAMLSS versus robust LMM

These approaches solve different problems.

  • robust LMM: reduces sensitivity to contamination under a Gaussian mixed-model framework;
  • GAMLSS: models the conditional distribution more flexibly, including parameter heterogeneity.

A heteroscedastic but valid dataset is not necessarily contaminated. An influential contaminated observation is not necessarily evidence that sigma should depend on treatment.

18 17. GAMLSS versus Bayesian distributional regression

Both can model multiple distributional parameters. The inferential frameworks differ.

GAMLSS here is fit in a likelihood-based framework. brms can fit distributional multilevel models with posterior distributions and priors. Choose based on the scientific and inferential needs, not package fashion.

Report:

  • link functions if non-default;
  • formulas for mu, sigma, nu, and tau that are actually modeled;
  • random/grouping structure;
  • correlation structure;
  • diagnostics;
  • candidate-comparison criterion;
  • conditional quantiles if used;
  • scientific interpretation of each distributional parameter.

21 20. Key take-home messages

  • GAMLSS models the conditional distribution, not only a mean.
  • Scale and shape effects need scientific interpretation.
  • Quantiles are distributional outputs, not confidence intervals for the mean.
  • Added distributional complexity should solve a diagnosed or scientifically motivated problem.
  • Do not confuse heteroscedasticity with contamination.
