1 Purpose

This vignette develops the core language of Gaussian mixed models: random intercepts, random slopes, nested and crossed grouping factors, variance components, BLUPs/conditional modes, shrinkage, and singular fits.

2 1. Learning objectives

You will learn to:

  • translate experimental or sampling hierarchy into random-effect terms;
  • distinguish a random intercept from a random slope;
  • distinguish nested from crossed grouping factors;
  • extract and visualize group-level effects;
  • understand partial pooling and shrinkage;
  • inspect random-effect covariance;
  • recognize overparameterized or singular random structures;
  • compare random structures without ignoring the design.

5 4. Random slope model

A random slope lets subjects differ in their rate of change over time.

if (requireNamespace("lme4", quietly = TRUE)) {
  rs <- mixed_random_slopes(
    data       = z,
    response   = "height",
    fixed      = "treatment * time",
    slope      = "time",
    group      = "subject",
    correlated = TRUE
  )

  rs
}

6 5. What the random-effect covariance means

For a correlated random-intercept/random-slope model, each subject has a pair of deviations:

  • baseline deviation;
  • slope deviation.

The estimated correlation asks whether subjects starting higher also tend to grow faster or slower.

  mixed_covariance_plot(
    rs,
    group = "subject",
    correlation = TRUE
  )
}

A correlation near +1 or -1 should be interpreted together with variance estimates and singularity diagnostics. It can signal insufficient information for the requested covariance structure.

8 7. Shrinkage and partial pooling

Suppose subject i has a noisy raw mean. A fixed-subject analysis would estimate it almost independently. A mixed model assumes subjects come from a population distribution and estimates a conditional deviation that balances:

  1. the subject’s own data;
  2. the estimated population mean trajectory;
  3. the estimated between-subject variance;
  4. residual uncertainty.

This is partial pooling.

8.1 Why shrinkage is useful

  • groups with little information are stabilized more strongly;
  • well-informed groups remain closer to their observed trajectory;
  • extreme group estimates are not automatically treated as errors;
  • prediction for new or partially observed groups becomes coherent.

Shrinkage is not arbitrary regularization added after fitting. It follows from the hierarchical model.

Do not add a random slope merely because it decreases AIC by a small amount. Ask whether trajectories truly vary by subject and whether the design supplies repeated observations across the relevant covariate range.

14 13. A deliberately weak random-slope problem

Create a subset containing only two time points.

z2 <- subset(z, time %in% c(min(time), max(time)))
if (requireNamespace("lme4", quietly = TRUE)) {
  rs_sparse <- try(
    mixed_random_slopes(
      data       = z2,
      response   = "height",
      fixed      = "treatment * time",
      slope      = "time",
      group      = "subject",
      correlated = TRUE
    ),
    silent = TRUE
  )

  if (inherits(rs_sparse, "try-error")) {
    cat("The engine refused to estimate this model:\n\n")
    cat(conditionMessage(attr(rs_sparse, "condition")), "\n")
  } else {
    mixed_diagnose(rs_sparse)
  }
}
#> The engine refused to estimate this model:
#> 
#> number of observations (=60) <= number of random effects (=60) for term (1 + time | subject); the random-effects parameters and the residual variance (or scale parameter) are probably unidentifiable

With two observations per subject, a correlated random slope asks the data for one intercept and one slope per subject plus a residual variance, which is as many random effects as there are observations. lme4 does not silently return a fragile answer here: it refuses, because the variance parameters and the residual are not separately identifiable. When the design is only slightly better supported, the fit succeeds but the covariance estimate is weak, and that is when mixed_diagnose() matters.

The point is not that two observations per subject always make a random slope impossible. The point is that covariance estimation becomes much less informative and should be diagnosed rather than assumed.

15 14. Fixed versus random: practical reasoning

A factor is not random merely because its labels are letters or numbers. Consider:

  • What population is the factor intended to represent?
  • Were levels sampled from a wider population?
  • Is the scientific target the individual level means or the between-level variance?
  • Is prediction to new levels relevant?
  • Does the design imply grouping-induced dependence?

Treatment factors are often fixed because specific levels are of direct scientific interest. Blocks, subjects, farms, sites, years, and genotypes can be fixed or random depending on the scientific estimand and sampling framework.

16 15. Reporting random effects

A high-quality report should provide more than the phrase “block was random.”

Report:

  1. each grouping factor;
  2. whether a random intercept, slope, or covariance was fitted;
  3. the grouping-unit count;
  4. variance and standard-deviation estimates;
  5. covariance/correlation when fitted;
  6. singularity and convergence status;
  7. whether BLUPs are used for interpretation or prediction.

18 17. Key take-home messages

  • Random effects describe modeled variation among groups or experimental units.
  • Random slopes model heterogeneity in response trajectories.
  • Nested and crossed structures describe design relationships.
  • BLUPs are conditional, partially pooled estimates, not raw group means.
  • A complex random covariance must be supported by the design and data.
  • Singularity is an inferential warning that deserves explanation.
