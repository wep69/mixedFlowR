1. Why this tutorial exists

Mixed models become difficult when several decisions are introduced at the same time: experimental hierarchy, fixed versus random effects, response distribution, covariance structure, repeated observations, spatial variation, influential observations, small-sample inference, nonlinear response, and prediction.

mixedFlowR is organized so that these decisions can be introduced in a logical order.

The central rule is simple:

Start with the experimental unit and the randomization. Then specify the model. Diagnose it before interpreting it. Report estimates with uncertainty.

This tutorial follows that rule from a basic split-plot experiment through advanced distributional, Bayesian, spatial, and multi-environment analyses.

The examples use the package’s frozen simulated teaching datasets. Their seed is 260818. They are realistic enough for instruction but are not field evidence. Numerical values shown in the descriptive tables below are observed summaries of those frozen teaching datasets. They are not model estimates and should not be interpreted as inferential results.

2. Learning objectives

After working through this tutorial, the reader should be able to:

  1. identify the experimental unit, hierarchy, replication, and possible pseudoreplication before fitting a model;
  2. connect classical split-plot error strata to a modern linear mixed model;
  3. distinguish random intercepts, random slopes, nested effects, and crossed effects;
  4. choose a response family for counts, proportions, and binary data;
  5. separate random-effect covariance from residual covariance;
  6. evaluate temporal correlation and heteroscedasticity;
  7. use robust estimation and bootstrap inference as sensitivity tools rather than automatic replacements for the primary analysis;
  8. analyze qualitative treatments through estimated marginal means and planned contrasts;
  9. analyze quantitative treatments through trends, curves, and biologically meaningful optima;
  10. fit nonlinear growth and dose-response mixed models;
  11. understand when a mixed GAMLSS or Bayesian multilevel model adds scientifically meaningful flexibility;
  12. use spatial field-trial and multi-environment modules;
  13. perform diagnostics and model comparisons with design-aware safeguards;
  14. produce reusable tables, figures, and a reproducible report skeleton;
  15. navigate all 70 package blocks without having to learn every function at once.

5.3 What to interpret

A design audit answers questions that no model-selection criterion can repair later:

  • Are all intended treatment combinations represented?
  • Which factor was randomized to the whole plot?
  • Which observations share an experimental unit?
  • Is a repeated measurement being mistaken for an independent replicate?
  • Are empty cells or missing treatment combinations present?
  • Does the proposed random structure reflect the actual randomization?

If these answers are uncertain, the next step is not model fitting. The next step is design clarification.

6.3 Why this comparison is educationally important

In a classical split-plot, the whole-plot treatment is tested against variation among whole plots within blocks, while subplot effects are tested against the subplot-level residual.

A mixed model represents the same hierarchy through random effects.

For this design, a common modern representation is:

if (requireNamespace("lme4", quietly = TRUE)) {
  fit_sp <- mixed_fit(
    yield ~ variety * nitrogen +
      (1 | block) +
      (1 | block:variety),
    data = d,
    engine = "lme4"
  )
}

The term (1 | block:variety) represents variability among whole plots. It is not decorative syntax. It corresponds to a real randomization level.

6.4 Basic interpretation

If the balanced legacy analysis and the equivalent LMM disagree materially, do not immediately choose the model with the preferred p-value. Check:

  1. whether nitrogen is being treated the same way in both models;
  2. whether the whole-plot experimental unit is correctly represented;
  3. whether the fixed-effect parameterization is comparable;
  4. whether missing observations or imbalance have altered the classical decomposition;
  5. whether one analysis is using a regression treatment of nitrogen and the other a categorical treatment.

7.5 How to interpret the result

Use the following order:

  1. Design validity: was the correct whole-plot random effect fitted?
  2. Convergence and singularity: is the fitted random structure estimable?
  3. Interaction: is there evidence that the nitrogen response differs among varieties?
  4. Main effects: interpret them conditionally if an interaction is important.
  5. Variance components: how much variability lies at block, whole-plot, and residual levels?
  6. Uncertainty: report intervals or appropriately calibrated tests, not estimates alone.
  7. Biological meaning: a statistically detectable slope can still be agronomically trivial.

8.4 Interpretation

A random intercept says that subjects can start at different levels.

A random slope says that subjects can also change at different rates.

The estimated subject effects are partially pooled. Extreme raw subject means are pulled toward the population pattern according to the information available for each subject and the estimated between-subject variation.

A near-perfect intercept-slope correlation, or a random-slope variance near zero, can indicate that the requested random structure is too complex for the available data. This is a diagnostic issue, not a reason to hide the warning.

m <- mixed_data("met")

Interpretation caution

A compact-letter display is a convenient communication device, but shared letters do not prove equality. They indicate that a particular multiplicity-adjusted comparison did not detect a difference at the chosen threshold.

Whenever possible, pair letters with estimates, uncertainty intervals, and the scientific scale of the difference.

10.4 Grid-based optimum

if (
  exists("qfit") &&
  requireNamespace("emmeans", quietly = TRUE)
) {
  opt <- mixed_optimum(
    qfit,
    variable  = "nitrogen",
    range     = c(0, 150),
    by        = "variety",
    objective = "max",
    n         = 501
  )

}

10.5 Interpretation

The optimum returned by mixed_optimum() is an estimand on the declared finite prediction grid. It is not proof of a global biological optimum outside the observed range.

For agronomic decisions, report the shape of the response, the estimated optimum inside the experimental range, uncertainty around the curve, biological plausibility, and whether an economic optimum would differ from the biological maximum.

14. Repeated measurements: random effects are not the whole dependence structure

Random intercepts and slopes model heterogeneity among subjects. Residual covariance models dependence that remains among observations from the same subject after the random effects and fixed effects are accounted for.

These are related but different components.

Interpretation

Use covariance structures that have a design or process interpretation.

  • AR(1): equally spaced visits where correlation decays by lag.
  • CAR(1): irregularly spaced time, where correlation decays continuously with distance in time.
  • Heterogeneous variance: treatment groups or occasions differ in residual variability.
  • Toeplitz: correlations can vary by lag without forcing a single exponential-decay parameter.

Prefer a simpler scientifically plausible structure when additional complexity is weakly supported or poorly estimated.

Stage B: random slope

m_rs <- mixed_random_slopes(
  z,
  response = "height",
  fixed    = "treatment * time",
  slope    = "time",
  group    = "subject"
)

Stage C: residual serial correlation

m_ar1 <- mixed_ar1(
  z,
  response = "height",
  fixed    = "treatment * time",
  time     = "time",
  group    = "subject",
  engine   = "nlme"
)

Stage D: heteroscedastic residuals

m_het <- mixed_heterogeneity(
  height ~ treatment * time,
  data           = z,
  random         = ~ time | subject,
  variance_group = "treatment"
)

Stage E: robust sensitivity

m_rob <- mixed_robust(
  height ~ treatment * time + (1 | subject),
  data = z
)

mixed_compare_robust(
  m_ri,
  m_rob
)

Stage F: bootstrap

m_boot <- mixed_boot_fixed(
  m_ri,
  B    = 1999,
  seed = 260818
)

Stage G: distributional scale model

m_gamlss <- mixed_gamlss(
  height ~ treatment * time,
  data          = z,
  family        = "NO",
  sigma.formula = ~ treatment,
  random        = "subject"
)

Stage H: Bayesian counterpart

m_bayes <- mixed_bayes(
  height ~ treatment * time + (time | subject),
  data   = z,
  chains = 4,
  iter   = 4000,
  seed   = 260818
)

Advanced interpretation template

Do not report this as eight competing algorithms. Report it as a sequence of scientific questions:

  1. Do subjects differ in baseline height?
  2. Do subjects differ in growth rate?
  3. Is serial dependence left after subject heterogeneity is modeled?
  4. Does residual variability differ by treatment?
  5. Are fixed-effect conclusions sensitive to influential observations?
  6. Are small-sample or asymmetric intervals materially different?
  7. Is modeling residual scale scientifically informative?
  8. Do Bayesian predictive checks and posterior uncertainty tell the same substantive story?

This question-driven framing is more informative than declaring a single “best model.”

Part X. Common mistakes and the corresponding functions

32. Treating every quantitative dose as a factor

Use a factor when levels are genuinely categorical treatments. Use trends or curves when the numeric scale carries scientific information.

mixed_quantitative()
mixed_trend()
mixed_curve()
mixed_optimum()

33. Ignoring the whole-plot error

A split-plot is not an ordinary factorial experiment with a single residual error term.

mixed_design_audit()
fit_legacy_splitplot()
splitplot_ems()
compare_legacy_mixed()
mixed_fit()

34. Adding random slopes without enough information

A maximal random structure is not automatically the correct structure.

mixed_random_slopes()
mixed_diagnose()
mixed_covariance_plot()
mixed_compare()

35. Choosing covariance only by the smallest AIC

Use information criteria as evidence about fit and parsimony, not as a substitute for the scientific process that generated dependence.

mixed_covariance()
mixed_ar1()
mixed_car1()
mixed_toeplitz()
mixed_covariance_compare()

36. Calling influential observations “outliers” and deleting them

Influence is a property of the fitted analysis, not a data-quality diagnosis.

mixed_influence()
mixed_robust_influence()
mixed_contamination()
mixed_compare_robust()
mixed_robust_vcov()

37. Using a Poisson model for any count automatically

Counts can be overdispersed, zero-inflated, clustered, or serially dependent.

mixed_count()
mixed_zero_inflated()
mixed_diagnose()
mixed_compare()

38. Interpreting non-significance as equality

This applies especially to compact-letter displays.

mixed_emmeans()
mixed_contrasts()
mixed_cld()

Report estimates and intervals alongside grouping letters.

39. Ignoring diagnostics because the model converged

Convergence is necessary, not sufficient.

mixed_diagnose()
mixed_influence()
mixed_plot()
mixed_pp_check()
mixed_gamlss_diagnose()

40. Using advanced models without a scientific reason

GAMLSS, Bayesian multilevel models, spatial smoothers, and factor-analytic GxE structures add flexibility. They also add assumptions, estimation burden, and interpretation requirements.

mixed_gamlss()
mixed_bayes()
mixed_spatial_field()
mixed_gxe()

Use complexity to solve a stated problem.

Appendix B. A single starter script

The following script is intentionally compact. It is suitable as the first file a new user creates after installing mixedFlowR.

library(mixedFlowR)

# 1. Inspect capabilities.
mixed_capabilities()

# 2. Load a teaching dataset.
d <- mixed_data("splitplot")

# 3. Audit the design.
audit <- mixed_design_audit(
  d,
  response = "yield",
  block    = "block",
  whole    = "variety",
  sub      = "nitrogen"
)
audit

# 4. Classical split-plot representation.
legacy <- fit_legacy_splitplot(
  d,
  "yield",
  "block",
  "variety",
  "nitrogen"
)
splitplot_anova(legacy)

# 5. Modern mixed representation.
if (requireNamespace("lme4", quietly = TRUE)) {
  fit <- mixed_fit(
    yield ~ variety * nitrogen +
      (1 | block) +
      (1 | block:variety),
    data = d
  )

  # 6. Diagnose.
  diag <- mixed_diagnose(fit)
  print(diag)

  # 7. Infer.
  if (
    requireNamespace("lmerTest", quietly = TRUE) &&
    requireNamespace("pbkrtest", quietly = TRUE)
  ) {
    print(
      mixed_anova(
        fit,
        ddf = "Kenward-Roger"
      )
    )
  }

  # 8. Quantitative treatment.
  if (requireNamespace("emmeans", quietly = TRUE)) {
    print(
      mixed_trend(
        fit,
        ~ variety,
        var = "nitrogen"
      )
    )

    print(
      mixed_plot(
        fit,
        type      = "curve",
        x         = "nitrogen",
        by        = "variety",
        values    = seq(0, 150, by = 2.5),
        show_data = TRUE
      )
    )
  }

  # 9. Scientific output.
  print(
    mixed_table(
      fit,
      component = "fixed"
    )
  )

  mixed_report(
    fit,
    "starter_mixedflowr_report.md",
    "Starter mixedFlowR analysis"
  )
}

Final perspective

A mixed-model workflow is strongest when the model can be explained as a consequence of the experiment.

For a beginner, the recommended sequence is:

design audit -> legacy design logic -> mixed fit -> diagnostics -> inference -> trends/contrasts -> figures/tables -> report.

For an advanced user, the sequence becomes:

design audit -> hierarchical model -> distribution and covariance -> diagnostics -> sensitivity/bootstrap -> distributional or Bayesian extension if justified -> spatial/MET structure if required -> publication and reproducibility.

The 70 blocks are therefore not 70 unrelated tools. They form one progressive analysis grammar. The purpose of mixedFlowR is to keep that grammar visible while allowing the analyst to move from a textbook split-plot to modern hierarchical, distributional, Bayesian, spatial, and multi-environment models without disconnecting the analysis from the experimental design.
