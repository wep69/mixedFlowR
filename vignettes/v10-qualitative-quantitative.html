1 Purpose

Agronomic experiments often combine a qualitative factor, such as cultivar or irrigation regime, with a quantitative factor, such as nitrogen dose, salinity, temperature, or time. Treating both factors identically can obscure the scientific question.

This vignette develops a principled workflow for estimated marginal means, planned contrasts, compact-letter displays, slopes, polynomial or spline curves, and grid-based optima.

2 1. Learning objectives

You will learn to:

  • identify when a predictor should remain quantitative;
  • use EMMs for qualitative factors;
  • construct planned and multiplicity-adjusted contrasts;
  • interpret compact-letter displays cautiously;
  • estimate marginal trends with mixed_trend();
  • create prediction curves with mixed_curve();
  • use polynomial or spline bases with mixed_quantitative();
  • locate a model-based optimum within a declared range;
  • avoid extrapolation beyond experimental support.

4 3. A conceptual decision table

Predictor Natural question Preferred output
variety Which levels differ? EMMs and contrasts
nitrogen dose How does response change with dose? slopes, curves, optimum
time What is the trajectory? trend/curve and dependence model
treatment × dose Do dose responses differ by treatment? interaction-specific curves/trends

5 4. Model for qualitative-by-quantitative interaction

Fit a quadratic nitrogen response with variety-specific shape.

if (requireNamespace("lme4", quietly = TRUE)) {
  fit_poly <- mixed_quantitative(
    data         = d,
    response     = "yield",
    quantitative = "nitrogen",
    qualitative  = "variety",
    group        = "block",
    degree       = 2,
    basis        = "polynomial"
  )
}

The polynomial representation is a mean model. It does not eliminate the need to diagnose the mixed model or represent whole-plot randomization correctly in a study where that hierarchy matters.

9 8. Marginal trends for nitrogen

For a model in which nitrogen appears in a form supported by emtrends, estimate local or marginal slopes.

if (requireNamespace("lme4", quietly = TRUE)) {
  fit_linear <- mixed_fit(
    yield ~ variety * nitrogen +
      (1 | block) +
      (1 | block:variety),
    data = d
  )
}
if (
  exists("fit_linear") &&
  requireNamespace("emmeans", quietly = TRUE)
) {
  tr <- mixed_trend(
    fit_linear,
    specs = ~ variety,
    var   = "nitrogen"
  )

  tr
}
#>  variety nitrogen.trend      SE df lower.CL upper.CL
#>  V1              0.0982 0.00925 51   0.0796    0.117
#>  V2              0.0955 0.00925 51   0.0770    0.114
#>  V3              0.0890 0.00925 51   0.0704    0.108
#> 
#> Degrees-of-freedom method: kenward-roger 
#> Confidence level used: 0.95

Interpretation. A slope is an expected change in yield per unit change in nitrogen on the scale defined by the fitted model. Compare slopes among varieties only when that comparison matches the scientific question.

11 10. Grid-based optimum

if (
  exists("fit_poly") &&
  requireNamespace("emmeans", quietly = TRUE)
) {
  opt <- mixed_optimum(
    fit_poly,
    variable  = "nitrogen",
    range     = c(0, 150),
    by        = "variety",
    objective = "max",
    n         = 501
  )

  opt
}
#>  nitrogen variety emmean   SE   df lower.CL upper.CL
#>       150 V1        64.2 1.54 13.3     60.9     67.5
#>       150 V2        68.8 1.54 13.3     65.5     72.1

#>

The result is the best predicted point on the declared grid. It is not a proof that the true biological response has a unique global maximum.

12 11. Linear basis

If the response is plausibly linear over the experimental range:

if (requireNamespace("lme4", quietly = TRUE)) {
  q_linear <- mixed_quantitative(
    d,
    response     = "yield",
    quantitative = "nitrogen",
    qualitative  = "variety",
    group        = "block",
    degree       = 1,
    basis        = "linear"
  )
}

Do not add curvature automatically. The polynomial order should reflect both scientific expectations and model adequacy.

13 12. Spline basis

A spline is useful when the response is smooth but not well represented by a low-order polynomial.

if (requireNamespace("lme4", quietly = TRUE)) {
  q_spline <- mixed_quantitative(
    d,
    response     = "yield",
    quantitative = "nitrogen",
    qualitative  = "variety",
    group        = "block",
    basis        = "spline",
    df           = 4
  )
}

A spline can be flexible, but it may make extrapolation and simple coefficient interpretation less meaningful. Prefer curve-based interpretation.

14 13. Compare mean structures for a scientific reason

if (exists("q_linear") && exists("fit_poly")) {
  mixed_compare(
    linear    = q_linear,
    quadratic = fit_poly,
    method = "information"
  )
}
#>       model engine                                           fixed npar
#> 1    linear   lme4                      yield ~ variety * nitrogen    8
#> 2 quadratic   lme4 yield ~ variety * poly(nitrogen, 2, raw = TRUE)   11
#>      logLik      AIC      BIC
#> 1 -189.5584 395.1168 413.3301
#> 2 -205.3648 432.7295 457.7728

This comparison is descriptive. The model choice should also consider residual patterns, biological plausibility, and uncertainty around curvature.

15 14. A deliberately bad practice: factorize every dose

d$nitrogen_f <- factor(d$nitrogen)
if (requireNamespace("lme4", quietly = TRUE)) {
  fit_factor <- mixed_fit(
    yield ~ variety * nitrogen_f +
      (1 | block) +
      (1 | block:variety),
    data = d
  )
}

This model can be legitimate if the doses are conceptually distinct treatments. It is less informative if the main objective is a dose-response curve or optimum.

16 15. Interaction interpretation

For a qualitative-by-quantitative interaction, useful statements include:

  • the expected slope differs among varieties;
  • the curvature differs among varieties;
  • treatment separation increases or decreases across the dose range;
  • the predicted optimum differs within the experimental range.

Avoid reporting a single variety main effect averaged over a strong variety-by-dose interaction without explaining that averaging.

18 17. Practical reporting template

A concise results paragraph should answer:

  1. Was the treatment-by-dose interaction important?
  2. What was the direction and shape of response?
  3. Where were treatment differences largest?
  4. What model-based optimum was estimated within the experimental range?
  5. How uncertain was the curve or optimum?
  6. Did diagnostics support the chosen mean structure?

20 19. Key take-home messages

  • Qualitative levels are usually interpreted through EMMs and contrasts.
  • Quantitative treatments are usually more informative as trends or curves.
  • Compact-letter displays are summaries of hypothesis tests, not proof of equality.
  • A predicted optimum must stay within a scientifically defensible range.
  • Show observed data together with the model-based curve and uncertainty whenever possible.
