1 Purpose

This vignette extends the mixed-model framework to non-Gaussian responses. The focus is not on memorizing distributions. The objective is to connect the measurement process to an appropriate conditional distribution, link function, random structure, and diagnostic workflow.

mixedFlowR uses lme4 and glmmTMB as principal GLMM engines, with glmmTMB providing especially broad support for negative-binomial, beta, zero-inflated, and dispersion models (Brooks et al. 2017).

2 1. Learning objectives

You will learn to:

  • distinguish binary/binomial, count, and continuous-proportion outcomes;
  • understand the role of the link function;
  • fit binomial, Poisson, negative-binomial, beta, and zero-inflated mixed models;
  • recognize overdispersion and excess-zero questions;
  • use simulation-based residual diagnostics when DHARMa is available;
  • compare candidate models without automatic model selection;
  • report effects on both link and response scales when useful.

3 2. A practical family map

Response Typical family Link Common complication
successes out of trials binomial logit overdispersion / grouping
insect count Poisson log overdispersion
overdispersed count negative binomial log zero inflation
proportion strictly in (0,1) beta logit boundary values
structural + sampling zeros zero-inflated family family-specific distinguish zero mechanisms

The distribution should be motivated by the response scale and data-generating process, not by which model gives the smallest AIC.

6 5. Negative-binomial alternatives

Fit NB2.

if (requireNamespace("glmmTMB", quietly = TRUE)) {
  nb2 <- mixed_count(
    count ~ treatment * time + (1 | plot),
    data   = cnt,
    family = "nbinom2"
  )
}

Fit NB1.

if (requireNamespace("glmmTMB", quietly = TRUE)) {
  nb1 <- mixed_count(
    count ~ treatment * time + (1 | plot),
    data   = cnt,
    family = "nbinom1"
  )
}

The parameterizations differ in how variance increases with the conditional mean. Use diagnostics and subject-matter knowledge rather than assuming one is universally preferable.

11 10. Boundary values: a deliberate failure

A standard beta distribution has support in the open interval (0,1).

be_bad <- be
be_bad$severity[1] <- 0
mixed_beta(severity ~ treatment + (1 | block), be_bad)

This example is not evaluated because it is intended to demonstrate an error. Do not silently add a small constant to every observation without a documented modeling rationale.

13 12. Link-scale versus response-scale interpretation

With a log link, additive effects on the linear predictor become multiplicative effects on the mean response.

With a logit link, additive effects are on log-odds. A response-scale probability or risk difference may be easier to communicate.

The reporting workflow should therefore distinguish:

  • coefficient scale;
  • transformed response scale;
  • contrast scale;
  • absolute versus relative effect.

15 14. A practical model-building sequence for counts

A defensible sequence is:

  1. specify the fixed and random structure from the design;
  2. fit a Poisson baseline if scientifically reasonable;
  3. inspect dispersion and residual diagnostics;
  4. move to a negative-binomial family if overdispersion is material;
  5. evaluate zero inflation only if diagnostics and biology support a second zero mechanism;
  6. add residual temporal/spatial structure if dependence remains;
  7. compare conclusions across reasonable candidates.

16 15. Reporting checklist for GLMMs

Report:

  • response definition and denominator when relevant;
  • distribution family;
  • link function;
  • random effects;
  • zero-inflation formula, if fitted;
  • dispersion formula, if fitted;
  • diagnostics;
  • effect scale used in interpretation;
  • estimates with confidence intervals;
  • multiplicity adjustment for multiple contrasts.

18 17. Key take-home messages

  • Distribution choice starts from the response-generating process.
  • Random effects account for grouping but do not automatically solve overdispersion or residual dependence.
  • Negative-binomial and zero-inflated models answer different questions.
  • Beta models require support strictly inside (0,1) unless a boundary-capable alternative is used.
  • Simulation-based diagnostics are highly useful for GLMMs.
  • A lower information criterion alone is not a scientific argument for complexity.
