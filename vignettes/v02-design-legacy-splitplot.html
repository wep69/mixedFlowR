1 Purpose

This vignette develops the design logic behind split-plot, split-split-plot, strip-plot, and repeated-measure experiments. It is deliberately placed before advanced mixed-model topics because the hierarchy of experimental units determines which model structures are scientifically defensible.

2 1. Learning objectives

You will learn to:

  • distinguish observation, experimental unit, and sampling unit;
  • identify whole-plot, subplot, and sub-subplot randomization levels;
  • detect common forms of pseudoreplication;
  • inspect design support and empty cells;
  • understand expected mean-square logic in a classical split-plot;
  • connect error strata to random effects in an LMM;
  • understand when the classical balanced ANOVA becomes inadequate;
  • recognize split-split and strip-plot structures.

3 2. Experimental units come before formulas

An experimental unit is the smallest unit that can independently receive a treatment under the randomization actually performed.

In a split-plot field trial, two treatment factors can have different experimental units.

Level Example Randomized to Consequence
block field replicate block controls large-scale field variation
whole plot variety / irrigation large plot whole-plot error for this factor
subplot nitrogen / spray rate subdivision subplot residual for this factor
observation yield sample measured subplot not automatically an independent replicate

A formula does not create randomization. It represents randomization that already happened.

5.1 What the audit can and cannot know

The software can inspect the declared columns and observed support. It cannot reconstruct undocumented field operations. If the whole-plot factor was physically applied at another scale, the analyst must provide that information.

8 7. How to read the error strata

For a balanced split-plot, the conceptual rule is:

  • whole-plot factor: tested against variation among whole plots within blocks;
  • subplot factor: tested against subplot residual variation;
  • whole-by-sub interaction: also uses subplot-level variation in the classical decomposition.

This is why ordinary two-way ANOVA is not a valid substitute for split-plot ANOVA.

10 9. Quantitative subplot treatment: a different question

A classical factor ANOVA asks whether dose levels differ. A regression-oriented mixed model asks how yield changes along a quantitative nitrogen scale.

if (requireNamespace("lme4", quietly = TRUE)) {
  fit_numeric <- mixed_fit(
    yield ~ variety * poly(nitrogen, 2) +
      (1 | block) +
      (1 | block:variety),
    data = d
  )
}
if (
  exists("fit_numeric") &&
  requireNamespace("emmeans", quietly = TRUE)
) {
  mixed_plot(
    fit_numeric,
    type      = "curve",
    x         = "nitrogen",
    by        = "variety",
    values    = seq(min(d$nitrogen), max(d$nitrogen), length.out = 61),
    show_data = TRUE
  )
}

This approach is often more useful when dose has a mechanistic or agronomic continuum.

15 14. Three common design failures

15.1 Failure 1: wrong replication count

Mistake: treating subplots as independent variety replicates.

Consequence: standard errors for the whole-plot factor can be severely underestimated.

Prevention: explicitly define the whole plot and random structure.

15.2 Failure 2: random effect chosen from software convention

Mistake: adding (1|block) because it is common, while omitting the whole-plot experimental unit.

Consequence: the model may not represent the randomization.

Prevention: derive grouping factors from field operations.

15.3 Failure 3: changing a quantitative factor to categorical only to obtain letters

Mistake: reducing a dose-response question to many pairwise tests.

Consequence: loss of shape information and potentially lower power.

Prevention: use mixed_trend(), mixed_curve(), and mixed_optimum() when the quantitative scale is meaningful.

16 15. Reporting a split-plot analysis

A methods section should report at least:

  1. block structure and number of blocks;
  2. whole-plot experimental unit;
  3. subplot experimental unit;
  4. treatment allocation and randomization;
  5. whether subplot treatment was modeled categorically or quantitatively;
  6. random-effects structure;
  7. estimation method;
  8. denominator-DF approach for fixed-effect tests when used;
  9. diagnostics and any sensitivity analysis;
  10. estimates with uncertainty.

17 16. Practice exercise: from wrong to correct

Fit the intentionally incomplete model below and compare its random-effect structure with the design-correct model.

if (requireNamespace("lme4", quietly = TRUE)) {
  wrong <- mixed_fit(
    yield ~ variety * nitrogen_f + (1 | block),
    data = d
  )

  correct <- mixed_fit(
    yield ~ variety * nitrogen_f +
      (1 | block) +
      (1 | block:variety),
    data = d
  )
}

Do not decide between them only from AIC. Explain which randomization level is missing from wrong.

18 17. Key take-home messages

  • Experimental-unit hierarchy is a property of the experiment, not the software.
  • Whole-plot and subplot treatments have different error scales.
  • Legacy ANOVA is highly valuable for teaching and balanced-design auditing.
  • Mixed models generalize the representation but do not remove the need to understand randomization.
  • Quantitative subplot treatments deserve regression-oriented interpretation when scientifically appropriate.
