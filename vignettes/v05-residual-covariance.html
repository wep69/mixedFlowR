1 Purpose

Random effects and residual covariance solve different modeling problems. Random effects represent heterogeneity among groups or experimental units. Residual covariance represents dependence that remains among observations after the fixed and random components have been specified.

This distinction is essential for repeated measures, longitudinal agronomic experiments, sensor series, and spatially structured trials.

2 1. Learning objectives

You will learn to:

  • distinguish random-effect covariance from residual covariance;
  • fit discrete AR(1) and continuous-time AR(1) residual structures;
  • fit heterogeneous residual variances;
  • understand Toeplitz and other structured covariance options;
  • compare plausible covariance candidates without automatic selection;
  • visualize estimated covariance/correlation matrices;
  • understand when nlme, lme4, and glmmTMB structures are not inferentially identical;
  • identify design situations where covariance complexity is unsupported.

4 3. Two sources of dependence

A subject-specific random intercept induces correlation because observations from the same subject share the same latent deviation.

if (requireNamespace("lme4", quietly = TRUE)) {
  ri <- mixed_random_intercepts(
    z,
    response = "height",
    fixed    = "treatment * time",
    group    = "subject"
  )
}

But repeated residuals may still be serially correlated after the random intercept is included. That residual pattern is a separate model component.

Questions to ask:

  • Does the model converge?
  • Is the covariance parameter near a boundary?
  • Does residual structure remain?
  • Is the more complex covariance estimable?
  • Are conclusions about fixed effects stable?
  • Is the covariance structure consistent with measurement timing?

16 15. Practical comparison strategy

A recommended progression is:

  1. establish the correct fixed and grouping structure;
  2. fit a scientifically plausible simple covariance model;
  3. inspect residuals and temporal/spatial patterns;
  4. add heterogeneity or covariance complexity only to address a defined problem;
  5. compare candidate models using fit descriptors and diagnostics;
  6. prefer the simpler structure when added flexibility is weakly identified.

17 16. Example: time-specific residual variances

z$time_f <- factor(z$time)

if (requireNamespace("nlme", quietly = TRUE)) {
  m_timevar <- mixed_heterogeneity(
    height ~ treatment * time,
    data           = z,
    random         = ~ 1 | subject,
    variance_group = "time_f"
  )
}

This model can become parameter-rich quickly. It is most useful when variance changes systematically by occasion and enough observations support each stratum.

18 17. Common mistakes

18.1 Mistake 1: assuming random intercepts remove all serial correlation

They do not. Random effects and residual dependence are different layers.

18.2 Mistake 2: applying discrete AR(1) to highly irregular times

Consider continuous-time correlation when actual intervals matter.

18.3 Mistake 3: choosing unstructured covariance by default

A flexible structure can be unstable and difficult to estimate with limited repeated observations.

18.4 Mistake 4: comparing AIC values from substantively different mean models

First ensure that the scientific estimand and fixed effects are comparable.

19 18. Reporting checklist

Report:

  • measurement schedule;
  • subject or plot grouping;
  • random-effect structure;
  • residual covariance structure and its level;
  • heteroscedastic variance function, if used;
  • engine;
  • covariance parameter estimates when interpretable;
  • diagnostics and model-comparison rationale.
