1 Purpose

This vignette is the recommended first contact with mixedFlowR. It follows one agronomic experiment from the experimental design to a model, diagnostics, inference, a quantitative treatment response, publication-oriented output, and a reproducible report skeleton.

The package is design-aware rather than engine-centered. The first question is not “Which function fits a mixed model?” but “What was randomized, to which experimental unit, and which observations share the same source of variation?”

1.1 Learning objectives

After completing this vignette, you should be able to:

  1. inspect the package capabilities and teaching datasets;
  2. audit an experimental design before modeling;
  3. understand the transition from legacy split-plot ANOVA to an LMM;
  4. fit and diagnose a Gaussian mixed model;
  5. obtain small-sample fixed-effect tests when the required backend is available;
  6. distinguish qualitative treatment comparisons from quantitative trends;
  7. create a table and figure suitable as a starting point for publication;
  8. generate a reproducible Markdown report skeleton;
  9. recognize when a specialized module is required.

2 1. The package workflow

A compact mixedFlowR analysis can be remembered as eight questions.

Question Typical function
What is the experimental hierarchy? mixed_design_audit()
Is the design balanced and supported? mixed_balance()
What model represents that hierarchy? mixed_fit()
Did estimation behave properly? mixed_diagnose()
What fixed-effect evidence is available? mixed_anova()
Is the treatment qualitative or quantitative? mixed_emmeans() / mixed_trend()
How should results be communicated? mixed_table() / mixed_plot()
How is the analysis documented? mixed_report()

The package delegates estimation to established R engines rather than recreating them. lme4 is the principal core backend for LMMs and GLMMs (Bates et al. 2015); other modules use engines such as nlme, glmmTMB, robustlmm, gamlss, brms, SpATS, and sommer when the scientific problem requires their capabilities.

5.1 Interpretation

The whole plot is the experimental unit for variety. Individual subplot observations inside the same whole plot are not independent replicates of the variety treatment. Nitrogen is applied at the subplot level, so it has a different error scale.

  • singularity;
  • residual pattern;
  • extreme residuals;
  • evidence of heteroscedasticity;
  • unmodeled temporal or spatial dependence, when relevant.

If the diagnostic structure is poor, inference should wait.

15 14. Key take-home messages

  1. Encode the experimental design before selecting an engine.
  2. The random structure should represent real experimental or sampling levels.
  3. Diagnostics precede inference.
  4. Qualitative and quantitative treatments require different estimands.
  5. Report estimates with uncertainty and observed data whenever possible.
  6. Specialized backends should be added because the scientific problem requires them, not because they are available.
