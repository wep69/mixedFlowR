1 Purpose

A statistically correct model can still be communicated poorly. This vignette presents mixedFlowR as a communication layer that converts fitted model objects into tidy numerical tables, observed-data figures, model-based curves, residual plots, random-effect displays, covariance heat maps, spatial surfaces, bootstrap plots, and reproducible report skeletons.

The central principle is that the data-frame result remains authoritative. Formatting does not change estimates.

2 1. Learning objectives

You will learn to:

  • create fixed-effect and variance-component tables;
  • render Markdown, LaTeX, HTML, and Word-ready tables;
  • create raw-data, residual, fixed-effect, random-effect, curve, covariance, bootstrap, and spatial plots;
  • show observed data together with estimates;
  • export 600 dpi raster and vector graphics;
  • distinguish estimates from uncertainty and raw data;
  • create a reproducible report skeleton.

3 2. Fit a working model

z <- mixed_data("longitudinal")

  fit <- mixed_fit(
    height ~ treatment * time + (time | subject),
    data = z
  )
}

10 9. Raw-data plot

if (exists("fit")) {
  mixed_plot(
    fit,
    type = "raw",
    x = "time",

  )
}

Observed-data plots should appear early in an analysis because they reveal features that summary tables can hide.

11 10. Residual diagnostic plot

if (exists("fit")) {
  mixed_plot(fit, type = "residuals")
}

The smoothed residual trend is a visual aid. It is not a formal goodness-of-fit test.

12 11. Fixed-effect interval plot

if (exists("fit")) {
  mixed_plot(fit, type = "fixed")
}

The current communication layer uses approximate 95% Wald intervals where standard errors are available. Label the interval method accurately in manuscripts.

13 12. Random-effect plot

if (exists("fit")) {
  mixed_plot(fit, type = "random")
}

A random-effect plot shows conditional deviations, not treatment means.

14 13. Response curves with observed data

if (
  exists("fit") &&
  requireNamespace("emmeans", quietly = TRUE)
) {
  mixed_plot(
    fit,
    type = "curve",
    x = "time",
    by = "treatment",
    values = seq(min(z$time), max(z$time), by = 0.1),
    show_data = TRUE
  )
}

Figure principle: show the observed data and uncertainty whenever possible. The model should not visually erase the data-generating evidence.

if (exists("fit")) {

20 19. Why isolated bar charts are discouraged

For continuous responses, a bar plus standard error hides:

  • distribution shape;
  • sample density;
  • outliers;
  • heteroscedasticity;
  • overlap among groups;
  • within-group variation.

Prefer observed points, distributions, model curves, or interval plots.

21 20. Figure captions should identify the estimand

A good caption distinguishes among:

  • raw observations;
  • fitted conditional values;
  • population-level estimates;
  • EMMs;
  • confidence or credible intervals;
  • posterior predictive distribution;
  • spatial trend;
  • random effects.

Do not call every model-derived line a “regression line” without explaining what it represents.

22 21. Generate a report skeleton

Use a temporary file for an evaluated demonstration.

if (exists("fit")) {

}

23 22. Suggested manuscript output package

For a typical agronomic article, prepare:

Table 1: design/sample summary.
Table 2: fixed effects or omnibus inference.
Table 3: EMMs, contrasts, or trends with uncertainty.
Figure 1: observed data plus model estimates.
Figure 2: diagnostic panel or scientifically meaningful random/spatial structure.
Supplement: variance components, alternative models, sensitivity analyses.

24 23. Reporting checklist

Before export, verify:

  • axis labels and units;
  • legend labels;
  • observed data displayed when appropriate;
  • uncertainty method identified;
  • no clipped text;
  • vector or 600 dpi raster resolution;
  • table digits appropriate to measurement precision;
  • caption defines estimand and model scale;
  • numerical table matches the fitted object.

25 24. Exercises

  1. Create raw, fixed, random, and curve plots from the same model and explain how each answers a different question.
  2. Render the fixed-effect table as Markdown and flextable and verify that the numerical values agree.
  3. Export a curve as PDF and TIFF; compare intended use rather than visual content.
  4. Create a spatial surface and write a caption that does not confuse spatial trend with genotype performance.

26 25. Key take-home messages

  • Formatting is a communication layer, not an inferential transformation.
  • Observed data and uncertainty should remain visible.
  • Figure captions must identify the estimand and interval type.
  • Use vector graphics or appropriate raster resolution for publication.
  • Keep an authoritative data-frame table behind every rendered table.
