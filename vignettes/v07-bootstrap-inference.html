1 Purpose

Mixed-model uncertainty is not always well summarized by a symmetric Wald interval. Variance components are constrained, random-effect structures can be close to boundaries, and small-sample fixed-effect tests can have nonstandard behavior.

This vignette introduces parametric bootstrap inference, variance-component bootstrap, prediction intervals, BCa/wild options where supported, and parametric-bootstrap model comparison.

2 1. Learning objectives

You will learn to:

  • distinguish a bootstrap distribution from the original sampling model;
  • obtain bootstrap intervals for fixed effects;
  • bootstrap variance components;
  • obtain bootstrap prediction intervals;
  • understand population versus conditional predictions;
  • use BCa or wild bootstrap when confintROB supports the fitted object;
  • choose a practical number of replicates for teaching versus scientific analysis;
  • report seeds, replication counts, interval type, and resampling method.

3 2. Baseline model

library(mixedFlowR)
z <- mixed_data("longitudinal")
if (requireNamespace("lme4", quietly = TRUE)) {
  fit <- mixed_fit(
    height ~ treatment * time + (1 | subject),
    data = z
  )
}

4 3. Why bootstrap?

A model-based bootstrap asks what estimates would be obtained if new datasets were generated repeatedly under the fitted model and the analysis were repeated.

The workflow is:

  1. fit the model;
  2. simulate a new response under the fitted model;
  3. refit the model;
  4. recompute the statistic;
  5. repeat many times;
  6. summarize the empirical distribution.

This procedure makes the computational burden explicit: 4,999 bootstrap replicates can mean roughly 4,999 model refits.

6 5. Production-scale fixed-effect bootstrap

boot_fixed <- mixed_boot_fixed(
  fit,
  B = 4999,
  level = 0.95,

Why 4,999 rather than a universal magic number? Because Monte Carlo precision depends on the tail probability being estimated, computational budget, and the stability required for the scientific conclusion. Report the selected B explicitly.

Interpretation. Population and conditional predictions answer different questions. The first concerns the fixed population trajectory; the second conditions on estimated subject effects.

12 11. BCa intervals

mixed_boot() delegates BCa support to confintROB for supported model classes.

if (
  requireNamespace("confintROB", quietly = TRUE) &&
  exists("fit")
) {
  boot_bca <- mixed_boot(
    fit,
    statistic = "fixed",
    B = 1999,
    method = "parametric",
    interval = "BCa",
    cluster = "subject",
    seed = 260818
  )
}

This is not evaluated during vignette build because it can be computationally expensive and depends on an optional backend.

13 12. Wild bootstrap

A wild bootstrap can be useful when the resampling scheme is intended to be less reliant on homogeneous residual variance assumptions and the backend supports it.

if (
  requireNamespace("confintROB", quietly = TRUE) &&
  exists("fit")
) {
  boot_wild <- mixed_boot(
    fit,
    statistic = "fixed",
    B = 1999,
    method = "wild",
    interval = "percentile",
    cluster = "subject",
    seed = 260818
  )
}

Always describe the actual implementation and cluster definition rather than reporting only the word “bootstrap.”

16 15. Monte Carlo error matters

If the bootstrap p-value or interval endpoint is near a decision threshold, rerun with a larger simulation count. A stable conclusion should not depend strongly on changing B from 999 to 4,999.

A useful reproducibility check is to run the same analysis with two documented seeds and verify that substantive conclusions do not change.

17 16. What bootstrap does not fix

Bootstrap inference does not rescue:

  • the wrong experimental unit;
  • an inappropriate response distribution;
  • unmodeled spatial/temporal dependence;
  • nonconvergence;
  • a scientifically implausible mean structure;
  • severe extrapolation beyond the data.

Fix structural model problems before resampling them thousands of times.

18 17. Reporting checklist

Report:

  • statistic bootstrapped;
  • parametric or wild method;
  • percentile or BCa interval;
  • number of replicates;
  • confidence level;
  • cluster definition if used;
  • seed;
  • prediction conditioning (re.form) if prediction intervals are reported;
  • any failed refits or convergence issues.

19 18. Exercises

  1. Compare bootstrap intervals with Wald intervals for the same coefficient.
  2. Increase B from 49 to 199 and observe Monte Carlo stabilization.
  3. Bootstrap a random-slope variance and inspect boundary behavior.
  4. Compare population and conditional prediction intervals.

20 19. Key take-home messages

  • Bootstrap inference is computationally intensive because models are refitted repeatedly.
  • Use small B only for teaching and syntax checks.
  • Variance components often benefit from asymmetric interval methods.
  • Population and conditional predictions are different estimands.
  • Always report the resampling method, replication count, interval type, and seed.
