1 Purpose

Many agronomic processes are intrinsically nonlinear: plant growth, germination, decomposition, nutrient uptake, dose response, and saturation. A polynomial can approximate curvature, but a mechanistic or phenomenological nonlinear function often yields parameters with clearer biological meaning.

This vignette develops logistic and Gompertz growth models, a four-parameter dose-response model, a generic nonlinear mixed-model interface, and polynomial random regression curves.

2 1. Learning objectives

You will learn to:

  • recognize when a nonlinear function is preferable to a high-order polynomial;
  • fit logistic and Gompertz growth mixed models;
  • interpret asymptote and timing parameters;
  • fit a four-parameter logistic dose-response mixed model;
  • provide pooled starting values;
  • use the generic mixed_nonlinear() interface;
  • fit random regression curves;
  • distinguish nonlinear fixed structure from random trajectory heterogeneity.

The implementation uses the self-starting logistic form with parameters Asym, xmid, and scal, with a random effect on Asym in the current wrapper.

5 4. Biological interpretation of logistic parameters

  • Asym: asymptotic response level;
  • xmid: time associated with the curve midpoint;
  • scal: controls transition steepness/time scale.

Because these are nonlinear parameters, their meaning is usually more interpretable than coefficients of a fourth-order polynomial.

14 13. Dose-response interpretation

Potential targets include:

  • lower and upper asymptotes;
  • midpoint dose;
  • transition scale/steepness;
  • predicted effective doses derived from the curve;
  • between-unit variation in curve parameters.

Do not extrapolate a toxicity or optimum claim beyond the experimental dose range without external biological support.

17 16. Nonlinear mixed model versus random regression

Nonlinear mixed model

  • imposes a named biological/phenomenological curve;
  • parameters often have direct meaning;
  • can be sensitive to starts and identifiability.

Random regression

  • approximates trajectories flexibly with polynomial basis functions;
  • useful for heterogeneous longitudinal trajectories;
  • parameters themselves may be less biologically intuitive.

18 17. Bayesian nonlinear template

mixed_nonlinear() can delegate a nonlinear brms formula to brms.

bf_growth <- brms::bf(
  biomass ~ Asym / (1 + exp((xmid - time) / scal)),
  Asym ~ 1 + (1 | plant),
  xmid ~ 1,
  scal ~ 1,
  nl = TRUE
)

bayes_growth <- mixed_nonlinear(
  bf_growth,
  data = g,
  engine = "brms",
  prior = nonlinear_priors,  # define priors on biologically interpretable parameters first
  chains = 4,
  iter = 4000,
  seed = 260818
)

Priors on nonlinear parameters need especially careful scale interpretation.

19 18. Reporting nonlinear models

Report:

  • curve equation or named self-start function;
  • fixed parameter structure;
  • random parameter structure;
  • starting-value method;
  • convergence diagnostics;
  • parameter estimates with uncertainty;
  • derived quantities such as asymptote or midpoint;
  • observed data with fitted curves;
  • experimental range and extrapolation limits.

21 20. Key take-home messages

  • Nonlinear functions can provide biologically meaningful parameters.
  • Starting values and parameter identifiability matter.
  • A lower AIC does not make a biologically implausible curve acceptable.
  • Random regression and nonlinear mixed models solve related but distinct trajectory problems.
  • Avoid extrapolation beyond experimental support.
