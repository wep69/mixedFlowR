# Local Validation of mixedFlowR on Windows

This procedure is intentionally detailed because the distributed source snapshot was built in an environment without R. A package should not be called validated until these steps have been executed locally and the resulting logs have been inspected.

## 1. Install the R toolchain

1. Install the current 64-bit R release. On 2026-08-18 the current Windows release is R 4.6.1. The package itself declares `R >= 4.2.0`.
2. Install the matching Rtools release when source compilation is needed.
3. Restart R/RStudio and verify:

```r
R.version.string
Sys.which(c("make","gcc","g++"))
```

Compiled tools are especially relevant for Stan/rstan, `gamlss` dependencies and other source packages.

## 2. Unzip the source snapshot

Place the extracted `mixedFlowR` directory in a short path without synchronization or permission restrictions, for example:

```text
D:/temp/mixedFlowR
```

Set the working directory to its parent or pass the full package path to the scripts below.

## 3. Install development dependencies

From a terminal:

```powershell
Rscript D:/temp/mixedFlowR/tools/install_dependencies.R D:/temp/mixedFlowR
```

The script installs the core build/check stack and reports optional scientific engines that remain absent. Install the backends required for the analyses you intend to validate.

A comprehensive backend installation may include:

```r
install.packages(c(
  "lme4", "reformulas", "nlme", "glmmTMB", "robustlmm", "confintROB",
  "clubSandwich", "lmerTest", "pbkrtest", "emmeans", "multcomp",
  "multcompView", "gamlss", "gamlss.dist", "brms", "posterior", "loo",
  "DHARMa", "performance", "influence.ME", "SpATS", "sommer",
  "flextable"
))
```

Do not install every heavy backend if it is not needed. `brms` requires a functioning Stan toolchain.

## 4. Regenerate roxygen2 documentation

This step is mandatory because roxygen comments are authoritative:

```powershell
Rscript D:/temp/mixedFlowR/tools/regenerate_docs.R D:/temp/mixedFlowR
```

Then inspect `NAMESPACE`. It must be generated by roxygen2 and contain the public exports from the source comments. Do not hand-edit it.

## 5. Run the complete validation script

```powershell
Rscript D:/temp/mixedFlowR/tools/validate_local.R D:/temp/mixedFlowR
```

The script runs:

1. `roxygen2::roxygenise()`;
2. `testthat::test_local()`;
3. the 70-block registry check;
4. `R CMD check --as-cran` through `rcmdcheck`;
5. `sessionInfo()`.

Archive the complete console log.

## 6. Run targeted backend tests

If a specialized backend is installed, rerun its test file explicitly after package loading. Examples:

```r
testthat::test_file("tests/testthat/test-nlme-covariance.R")
testthat::test_file("tests/testthat/test-glmmtmb.R")
testthat::test_file("tests/testthat/test-robust-bootstrap.R")
testthat::test_file("tests/testthat/test-gamlss-bayes-specialized.R")
```

A skipped test is not a passed test. If `brms`, `SpATS`, `sommer` or another optional engine is missing, document that branch as unvalidated on that machine.

## 7. Render the vignettes

```r
pkgdown::build_articles("D:/temp/mixedFlowR")  # optional if pkgdown is installed
```

or build/install the package with vignettes enabled. Verify all equations, tables, plots, citations and code chunks visually.

## 8. Run the frozen simulation battery

The package ships defined scenarios in:

```text
inst/metadata/simulation_scenarios.csv
```

The executable validation script is:

```text
data-raw/simulations/run_validation_simulations.R
```

After installing `mixedFlowR`, source the file and call:

```r
source("data-raw/simulations/run_validation_simulations.R")
results <- run_all(n_rep = 1000L)
```

Do not alter the seeds or scenario definitions for publication runs without versioning the change. Store the RDS/CSV outputs, the package version and `sessionInfo()` together.

## 9. Inspect graphical outputs

For publication figures, explicitly test both vector and 600-dpi raster output:

```r
d <- mixed_data("longitudinal")
m <- mixed_fit(height ~ treatment*time + (1|subject), d)
mixed_plot(m, "raw", x="time", by="treatment", file="raw.pdf")
mixed_plot(m, "residuals", file="residuals.tiff", dpi=600)
```

Inspect fonts, clipping, axis labels, observed data, uncertainty bands and resolution.

## 10. Inspect table outputs

```r
mixed_table(m,"fixed")
mixed_table(m,"fixed",format="markdown")
mixed_table(m,"fixed",format="latex")
mixed_table(m,"fixed",format="html")
if(requireNamespace("flextable",quietly=TRUE)) mixed_table(m,"fixed",format="flextable")
```

Confirm that numerical precision and interval labels are scientifically appropriate for the intended manuscript.

## 11. Release gate

Do not release or claim full validation unless all of the following are documented:

- no `R CMD check` errors;
- warnings/notes reviewed and justified;
- all required backend tests actually executed;
- vignettes rendered without broken links or references;
- frozen simulations completed for the validation claims being made;
- graphical files visually inspected;
- reference metadata rechecked;
- package version, R version and dependency versions archived.
