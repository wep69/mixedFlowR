# mixedFlowR 10-page cheatsheet content map

This file defines the scientific content for a later 10-page visual cheatsheet. It is not an image/PDF artifact.

1. **Design first**: `mixed_design_audit()`, `mixed_hierarchy()`, `mixed_balance()`, `mixed_pseudorep()`.
2. **Legacy to LMM**: split-plot EMS, `fit_legacy_splitplot()`, `compare_legacy_mixed()`, `mixed_fit()`.
3. **Random structures**: intercepts, slopes, nesting, crossing, BLUP/shrinkage.
4. **GLMM families**: binomial, Poisson/NB, beta, zero inflation and dispersion.
5. **Dependence**: residual heterogeneity, AR1/CAR1, Toeplitz, OU, spatial covariance.
6. **Robust and bootstrap**: `mixed_robust()`, influence, contamination sensitivity, parametric/wild/BCa intervals.
7. **GAMLSS and Bayesian**: distributional parameters, priors, prior predictive checks, posterior/PPC/LOO.
8. **Qualitative × quantitative and nonlinear**: EMMs, trends, curves, splines, optima, growth and dose-response.
9. **Agronomic advanced**: SpATS field surfaces, MET, GxE covariance and reduced-rank/factor-analytic models.
10. **Integrated workflow**: design → fit → diagnose → infer → sensitivity → publication table/figure → reproducibility report.
