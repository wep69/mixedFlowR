# Reference Verification

Core methodological/software references were checked against two independent metadata-bearing sources whenever practical, normally the journal/publisher page plus CRAN package citation/documentation. The machine-readable record is `inst/metadata/reference_verification.csv` and the importable bibliography is `references/mixedFlowR_references.ris`.

No DOI should be treated as verified merely because it appears in a secondary bibliography. Before manuscript submission, rerun the metadata audit because journal metadata can be corrected after publication.
